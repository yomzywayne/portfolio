Machine Learning for Neutrino Interaction Classification

2025 | MSc Project

Applied Convolutional Neural Networks to classify neutrino interactions in simulated DUNE Near Detector Liquid Argon TPC data.

  • Achieved ~87% test accuracy; evaluated using ROC curves, precision, recall, and confusion matrices
  • Implemented regularisation (L1 penalty, dropout, pruning) and patience-based early stopping
  • Delivered reproducible pipeline, baseline CNN model, and comprehensive evaluation suite
